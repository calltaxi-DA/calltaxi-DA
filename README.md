서울 장애인콜택시 대기시간 분석 프로젝트

## 프로젝트 목적
이 프로젝트는 서울시 장애인콜택시 대기시간에 영향을 주는 요인을 분석하고, 대기시간 패턴을 탐색하며, 필요 시 예측 모델을 통해 운영 의사결정에 활용할 수 있도록 구성합니다.

## 브랜치 전략
- `main`: 최종 안정 버전
- `dev`: 통합 개발 브랜치
- `feat/data-ingestion`: 데이터 수집, 원본 로딩, ETL 연결
- `feat/data-preprocessing`: 결측치 처리, 이상치 제거, 전처리 및 정제
- `feat/eda`: 탐색적 데이터 분석, 시각화, 패턴 파악
- `feat/modeling`: 모델 실험, 성능 비교, 예측 코드
- `feat/dashboard`: Streamlit 등 결과 대시보드 구현

## 폴더 구조
```text
calltaxi-DA/
├── data/
│   ├── raw/                # 원본 데이터 (대용량 데이터는 Git 추적 제외 권장)
│   └── processed/          # 전처리된 데이터 저장
├── notebooks/              # EDA 및 실험용 노트북
├── src/
│   ├── __init__.py
│   ├── data_ingestion/     # 데이터 수집 및 로딩 코드
│   └── preprocessing/      # 전처리 및 정제 코드
├── .gitignore
├── README.md
└── requirements.txt        # 추후 추가 예정
```

## 작업 흐름
1. 데이터 수집 및 로딩
2. 전처리 및 정제
3. EDA 및 패턴 분석
4. 모델링 및 성능 검증
5. 결과 대시보드 구성

## 주의사항
- 대용량 원본 데이터는 Git에 올리지 않고 로컬 또는 외부 저장소에 보관하는 것이 좋습니다.
- `.gitignore`에 데이터 경로를 추가해 불필요한 추적을 방지합니다.
- 브랜치별 작업 후에는 `dev` 브랜치로 병합하는 방식으로 관리합니다.
